# 3d Map Client

### Version 1.420.69

## DO NOT MODIFY FILES IN /WES/

Typescript files located in /src/
Javascript and jsp files located in /wesFiles/

## To Build:

### Build Directly into WES

Ant target: CesiumDev (Will replace hosted files for quick debug)

### Build for production commit

Ant target: Cesium (Will build a release version and move files to wes/web/Cesium)

### Build Src for MANUAL installation into WES:

Development build: 'npm run build'
Production build: 'npm run build-release'
